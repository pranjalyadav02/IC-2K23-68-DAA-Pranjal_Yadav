# Task 4: Student Record Manager

This program stores sample student records. It can display records, sort them by roll number, name or marks, search by roll number, and compare sorting methods.

## Complexity
- Sorting: depends on the selected algorithm (see the sorting methods in the program).
- Binary Search by roll number: O(log n), after sorting the records by roll number.
- Display: O(n) time.
- Extra space: varies by sorting algorithm; the program copies records before sorting.

## Run
`python student_record.py`
