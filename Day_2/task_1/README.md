# Task 1: Sorting Algorithms and Binary Search

This folder contains one program with seven sorting methods: Bubble, Selection, Insertion, Merge, Quick, Heap and Radix Sort. It also includes Binary Search.

## Complexity

| Algorithm | Time complexity | Extra space |
|---|---:|---:|
| Bubble Sort | O(n²), best O(n) | O(1) |
| Selection Sort | O(n²) | O(1) |
| Insertion Sort | O(n²), best O(n) | O(1) |
| Merge Sort | O(n log n) | O(n) |
| Quick Sort | Average O(n log n), worst O(n²) | O(n) in this simple version |
| Heap Sort | O(n log n) | O(1) |
| Radix Sort | O(d(n + 10)) | O(n + 10) |
| Binary Search | O(log n) | O(1) |

Here, n is the number of values and d is the number of digits in the largest value. Binary Search needs a sorted list.

## Run
`python sorting.py`
