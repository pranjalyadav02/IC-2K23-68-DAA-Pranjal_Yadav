# Task 1: Find Maximum and Merge Sort

The program finds the largest value in a list and then sorts the list in ascending order using Merge Sort.

## How it works
- **Find maximum:** Start with the first value and compare it with the remaining values.
- **Merge Sort:** Split the list into halves, sort each half, and merge the sorted halves.

## Complexity

| Operation | Time | Extra space |
|---|---:|---:|
| Find maximum | O(n) | O(1) |
| Merge Sort | O(n log n) | O(n) |

## Run
`python main.py`
