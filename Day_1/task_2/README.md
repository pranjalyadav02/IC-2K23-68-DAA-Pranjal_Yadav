# Task 2: Stack and Queue

This program processes the same list of tasks using a stack and a queue.

- **Stack (LIFO):** The last task added is completed first.
- **Queue (FIFO):** The first task added is completed first. A printer queue is a common example.

## Complexity
For n tasks, both functions take O(n) time and O(n) extra space.

## Run
`python main.py`
