Part 2: Stack and Queue Execution Order

Given incoming tasks in order: Task1, Task2, Task3, Task4, Task5

1. If served using a Stack (LIFO - Last In First Out):
Completion order: Task5, Task4, Task3, Task2, Task1

2. If served using a Queue (FIFO - First In First Out):
Completion order: Task1, Task2, Task3, Task4, Task5

3. Printer Question:
A printer prints jobs in the order they arrive.
- Structure to use: Queue (FIFO)
- Printing order: Task1, Task2, Task3, Task4, Task5
