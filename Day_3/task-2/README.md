# Task 2: 2D Array Operations

The program can insert and delete rows, search for a value and rotate a rectangular 2D array 90 degrees clockwise.

## Complexity
For an r by c matrix:
- Search: O(r × c) time
- Insert or delete a row: O(r) time, excluding the row data
- Rotate: O(r × c) time and O(r × c) extra space

## Run
`python 2d_array_operation.py`
