# Task 1: 1D Array Operations

The program supports inserting an element, deleting an element, searching for a value, reversing the array and displaying the array.

## Complexity
- Insert or delete at an index: O(n) time
- Search: O(n) time
- Reverse: O(n) time
- Display: O(n) time
- Extra space: O(1) for search/reverse; O(1) apart from the input array

## Run
`python array_operations.py`
